Mail Guard

協助帳號擁有者搜尋郵件、整理通知，以及辨識可能的釣魚信。

Google OAuth 設定中的應用程式名稱為 Gmail read-only。 本工具另有分開授權的警示標籤模組；唯讀功能和標籤功能的權限不同。

功能與使用方式

這是開發者自用、在 Windows 電腦執行的工具，不是公開提供信箱代管或登入的服務。 本網站只提供應用程式資訊，不接受 Google 登入、不讀取訪客信件，也不收集 OAuth 憑證。

  • 透過 Gmail API 搜尋信件、讀取主旨、寄件者、內文、對話與標籤，以及彙整寄件者數量。
  • 以本機規則檢查寄件網域、驗證結果、連結與附件特徵；使用者可透過 Copilot 複核結果。
  • 在另外同意標籤權限後，替可疑或待確認的信件新增警示標籤。
  • 依帳號擁有者設定，將特定通知整理到本機報告或指定的試算表；相關附件可能保存在指定資料夾。

Google API 權限

gmail.readonly 用於讀取信件與標籤，這個模組不能寄信或修改信件。 gmail.modify 用於獨立的警示標籤模組。Google 授予的 modify 權限本身較廣， 但目前標籤程式只建立兩個警示標籤並將其中一個加到指定信件，不提供寄信、刪信或移除標籤的操作。

資料處理

資料可能由本機程式、使用者選用的 Copilot，以及選擇啟用的 TypeSafe Jev 輔助分析流程處理。 使用者指定的雲端同步資料夾也可能同步報告。詳細範圍、儲存方式、第三方處理及撤回授權方式， 請參閱隱私權政策及使用條款。

不是安全保證

警示只供人工複核，可能漏判或誤判；沒有標籤不代表信件安全。請勿因分析結果就提供密碼、 開啟可疑連結或執行附件。
