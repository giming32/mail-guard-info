隱私權政策

生效日期：2026-11-10 · 適用工具：Mail Guard（Google OAuth 名稱：Gmail read-only）

本政策說明此個人用途郵件工具如何存取、使用、保存及處理 Google 使用者資料。 本公開網站僅提供說明，與實際讀信及標籤程式分離。

1. 存取與用途

在帳號擁有者明確授權後，工具可讀取信件識別碼、對話、寄收件資訊、主旨、時間、內文、 Gmail 標籤、驗證資訊及附件資訊，用於郵件搜尋、通知整理與釣魚風險提示。 特定通知整理功能也可能讀取相關附件，保存到使用者指定的檔案或試算表。

唯讀模組要求 gmail.readonly。另外啟用的警示標籤模組要求 gmail.modify，用於建立或加上「可疑」及「待確認」警示標籤。 這項 Google 權限本身不僅限於加標籤；限制由目前的本機程式另外實施。 本工具目前沒有以郵件 API 寄信、刪信、建立草稿或變更轉寄設定的功能。

2. 本機儲存與保留

Google OAuth 用戶端資料與 refresh token 以 Windows CurrentUser DPAPI 加密保存於使用者電腦； 短期 access token 在執行過程中使用。報告、規則、掃描進度、回饋與所選通知紀錄可能保存在本機。 指定存到 OneDrive 等同步資料夾的資料，會受該同步服務的設定與政策影響。

目前沒有統一的自動刪除期限。使用者可停止排程，並自行刪除本機資料、附件、試算表及同步副本； 刪除某個檔案不一定會移除同步服務、備份或其他服務中的副本。

3. Copilot 與其他第三方處理

使用者透過 Copilot 呼叫 Gmail MCP 或檢視自動化結果時，相關郵件內容或分析結果可能提供給 Copilot 及使用者選擇的模型服務處理，依其帳號設定、合約及隱私權條款辦理； 不能將這種情況描述為所有資料都只在本機處理。

選擇啟用 TypeSafe Jev 輔助檢查時，流程設計為先在本機排除私人及敏感信件， 並對部分非私人可疑郵件的安全證據做去識別處理。送出的證據可能包含寄件及連結網域、 品牌與驗證結果、附件類型、寄件歷史彙整，以及經處理的主旨或短摘錄。 去識別與排除規則不代表絕對不會漏掉敏感資訊，啟用前應依使用者的資料限制確認設定。

本工具不出售 Google 使用者資料、不以其投放或個人化廣告，也不以其訓練或改善一般用途的 AI／機器學習模型。資料只用於使用者要求的上述功能。 本工具對來自 Google API 的資訊之使用及轉移，遵循 Google API Services User Data Policy， 包括 Limited Use 要求。

4. 撤回與刪除

可在 Google 帳戶的第三方連線設定移除此應用程式的存取權， 並停止本機排程。工具也提供撤銷及刪除本機授權檔的指令。若多個模組共用同一 OAuth 用戶端， 撤銷可能影響其他模組，需要重新授權。

撤回 Google 授權不會自動刪除已下載的報告、附件、同步副本或已加入的 Gmail 標籤。 請依需要分別管理。對 Copilot、TypeSafe 或同步服務保存的資料，應依各服務的控制與流程處理。

5. 本網站與聯絡方式

本網站由 GitHub Pages 託管，沒有額外的追蹤分析、廣告、表單或 Google 登入按鈕。 GitHub 可能為託管、安全及提供服務而處理連線紀錄，詳見 GitHub 隱私權聲明。

問題可透過公開 Issues提出； 切勿附上信件內容、個人聯絡資料、授權碼、token 或金鑰。Google 同意畫面所列的支援電子郵件 也是聯絡管道。本政策會隨實際資料用途更新，並標示生效日期。

個人用途的獨立工具，非 Google 官方產品，與 Google 無隸屬或背書關係。
問題回報：公開說明網站的 Issues（請勿提交信件、帳號資料、授權碼或憑證）。
